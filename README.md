Crunchy Data is a PostgreSQL company offering Crunchy Bridge, a fully managed cloud Postgres service on AWS, Azure and GCP, Crunchy Postgres for Kubernetes (the PGO operator), Crunchy Data Warehouse and supported Postgres distributions. Crunchy Bridge exposes a REST platform API at api.crunchybridge.com for managing clusters, networks, teams, backups, replicas and roles. Crunchy Data was acquired by Snowflake in 2025; crunchydata.com still serves its own site, while its privacy and Bridge terms links now point to snowflake.com.

**Areas:** Company · Database · PostgreSQL · Managed Database · Cloud · Kubernetes · Database-as-a-Service

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Crunchy Data: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
